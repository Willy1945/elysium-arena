🎨 Cara Mengedit File Cover Ini di Figma (3 Langkah Cepat)

File SVG yang kami buat menggunakan struktur standar web vector. Ketika dimasukkan ke Figma, seluruh grup, teks, dan ikon otomatis menjadi Native Figma Layers.

1

Import ke Canvas Figma

Buka Figma di peramban atau desktop. Buka proyek baru, lalu cukup Tarik & Lepaskan (Drag & Drop) berkas cover_depan_elysium_arena.svg dan cover_belakang_elysium_arena.svg langsung ke dalam lembar kerja Figma.

2

Edit Teks Nama & Data Sekolah

Pilih Text Tool (tombol T). Klik 2x pada teks nama Robi Purnama, NISN, atau Nama Pembimbing untuk mengubah data sesuai identitas Anda tanpa merusak tata letak.

3

Ekspor ke PDF Siap Cetak

Pilih Frame cover di panel layer Figma, lalu pada menu inspector sebelah kanan pilih Export → pilih format PDF (atau PNG 2x/3x) untuk langsung dicetak di percetakan.
